Materi coding html

Struktur utama html

1. Membuat file HTML

Buat file baru lalu simpan dengan ekstensi .html. Setelah itu buka file-nya di browser.

Kodenya:

<!DOCTYPE html>
<html>
    <head>
        <title>Latihan HTML RevoU 2</title>
    </head>
    <body>
        <h1>Hallo World test 11</h1>
    </body>
</html>

Hasilnya:

Hallo World test 11

Komponen dasar dari file html

1. Membuat tulisan di HTML

Pakai <h1></h1> untuk heading 1, <h2></h2> untuk heading 2, dan seterusnya sampai heading 6. Untuk tulisan biasa pakai <p></p>.

<h1>Ini Heading 1</h1>
<h2>Ini Heading 2</h2>
<h3>Ini Heading 3</h3>
<h4>Ini Heading 4</h4>
<h5>Ini Heading 5</h5>
<h6>Ini Heading 6</h6>

Hasilnya:

Ini Heading 1

Ini Heading 2

Ini Heading 3

Ini Heading 4

Ini Heading 5
Ini Heading 6

2. Enter dan garis pemisah

<br> dipakai untuk enter (pindah baris). <hr> dipakai untuk membuat garis.

<p>Untuk menggunakan fungsi br, tulis seperti ini</p>
<br>
<p>Nah, seperti ini</p>

<p>Untuk menggunakan fungsi hr, tulis seperti ini</p>
<hr>
<p>Nah, seperti ini</p>

Hasilnya:

Untuk menggunakan fungsi br, tulis seperti ini


Nah, seperti ini

Untuk menggunakan fungsi hr, tulis seperti ini

Nah, seperti ini

Catatan: di catatan sebelumnya saya menulis <tr> untuk garis. Itu salah, yang benar <hr>. Tag <tr> dipakai untuk baris tabel.

3. Tulisan tebal, miring, sub, dan sup

<b></b> untuk tebal (bold), <i></i> untuk miring (italic), <sub></sub> untuk tulisan kecil di bawah, <sup></sup> untuk tulisan kecil di atas.

<p><b>Nama saya Surya</b></p>
<p><i>Nama saya Surya</i></p>
<p>Hallo <sub>saya Surya</sub> dan ini adik saya <sup>Keenan</sup></p>

Hasilnya:

Nama saya Surya

Nama saya Surya

Hallo saya Surya dan ini adik saya Keenan

4. List

a. List biasa (ul)

Pakai <ul></ul>, isinya pakai <li></li> untuk setiap item. Bentuk titiknya diatur dengan type: disc, circle, square, atau none.

<ul type="circle">
    <li>HTML</li>
    <li>JavaScript</li>
    <li>C++</li>
    <li>Python</li>
</ul>

Hasilnya:

Macam-macam bahasa pemrograman

  • HTML
  • JavaScript
  • C++
  • Python

b. List angka (ol type="1")

<ol type="1">
    <li>HTML</li>
    <li>JavaScript</li>
    <li>C++</li>
    <li>Python</li>
</ol>

Hasilnya:

  1. HTML
  2. JavaScript
  3. C++
  4. Python

c. List huruf (ol type="a")

<ol type="a">
    <li>HTML</li>
    <li>JavaScript</li>
    <li>C++</li>
    <li>Python</li>
</ol>

Hasilnya:

  1. HTML
  2. JavaScript
  3. C++
  4. Python

5. Tabel

Tabel dibuat dengan <table></table>. Di dalamnya ada:

  1. <tr></tr> = table row (baris)
  2. <th></th> = table head (judul kolom)
  3. <td></td> = table data (isi tabel)

Supaya ada garisnya, tambahkan CSS ini setelah head:

<style>
    table, th, td {
        border: 1px solid blue;
    }
</style>

a. Tabel biasa

<table>
    <tr>
        <th>Nama</th>
        <th>NIM</th>
        <th>Kelas</th>
    </tr>
    <tr>
        <td>Pratama Surya Dinata</td>
        <td>122230048</td>
        <td>TI-B</td>
    </tr>
    <tr>
        <td>Keenan Nur Rafii</td>
        <td>122230049</td>
        <td>TI-B</td>
    </tr>
</table>

Hasilnya:

Nama NIM Kelas
Pratama Surya Dinata 122230048 TI-B
Keenan Nur Rafii 122230049 TI-B

b. Gabung kolom (colspan)

Pakai colspan="2" atau lebih untuk menggabungkan beberapa kolom jadi satu.

<table>
    <tr>
        <th>Nama</th>
        <th>NIM</th>
        <th>Kelas</th>
    </tr>
    <tr>
        <td colspan="3"><center><b>DATA</b></center></td>
    </tr>
    <tr>
        <td>Pratama Surya Dinata</td>
        <td>122230048</td>
        <td>TI-B</td>
    </tr>
    <tr>
        <td>Keenan Nur Rafii</td>
        <td>122230049</td>
        <td>TI-B</td>
    </tr>
</table>

Hasilnya:

Nama NIM Kelas
DATA
Pratama Surya Dinata 122230048 TI-B
Keenan Nur Rafii 122230049 TI-B

c. Gabung baris (rowspan)

Pakai rowspan="2" atau lebih untuk menggabungkan beberapa baris jadi satu. Tabel di bawah hanya 2 baris, jadi saya pakai rowspan="2".

<table>
    <tr>
        <th rowspan="2">Kota</th>
        <td>Jakarta</td>
        <td>Bandung</td>
    </tr>
    <tr>
        <td>Bogor</td>
        <td>Bekasi</td>
    </tr>
</table>

Hasilnya:

Kota Jakarta Bandung
Bogor Bekasi

6. Menambahkan gambar

Gambar dimasukkan dengan tag <img>. Tag ini tidak perlu ditutup. Simpan file gambarnya di folder yang sama dengan file HTML, lalu tulis nama file-nya di src.

  • src = nama file gambar (atau lokasi file-nya)
  • alt = tulisan pengganti kalau gambar tidak muncul
  • width = lebar gambar
  • height = tinggi gambar
<img src="Logo Apsi.png" alt="Logo APSI" width="300">

Hasilnya:

Kalau gambarnya ada di folder lain, tulis folder-nya di depan nama file.

<img src="gambar/foto.jpg" alt="Foto saya" width="200">

Catatan: kalau gambar tidak muncul, cek nama file-nya (huruf besar dan kecil berpengaruh) dan cek apakah file gambar satu folder dengan file HTML.

7. Menambahkan map

Map dari Google Maps dimasukkan dengan tag <iframe>. Caranya: buka Google Maps, cari lokasinya, klik Bagikan, pilih Sematkan peta, lalu salin kode HTML-nya dan tempel di file.

Kodenya (link panjang di src saya singkat jadi ...):

<iframe src="https://www.google.com/maps/embed?pb=..."
    width="600" height="450" style="border:0;"
    allowfullscreen="" loading="lazy"></iframe>
  • src = link embed dari Google Maps
  • width = lebar peta
  • height = tinggi peta
  • style="border:0;" = menghilangkan garis di pinggir peta

8. Menambahkan link dan link map

a. Link biasa

Link dibuat dengan tag <a></a>. Alamat tujuan ditulis di href. Kalau ditambah target="_blank", link akan terbuka di tab baru.

<a href="https://www.upnyk.ac.id/" target="_blank">Buka website RevoU</a>

Hasilnya:

Buka website

b. Link ke map (Google Maps)

Caranya: buka Google Maps, cari lokasinya, klik Bagikan, lalu salin link-nya dan tempel di href.

<a href="https://maps.app.goo.gl/yBkakUMZJNn6vBmS7" target="_blank">Lihat lokasi di Google Maps</a>

Hasilnya:

Lihat lokasi di Google Maps

c. Gambar yang bisa diklik

Tag <img> bisa dimasukkan ke dalam <a>, jadi gambarnya berfungsi sebagai link.

<a href="https://www.upnyk.ac.id/" target="_blank">
    <img src="Logo upn.png" alt="Klik untuk buka map" width="200">
</a>
